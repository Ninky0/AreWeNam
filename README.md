# Weather Wear, What to Wear ; WWWW

*날씨*에 따라 *옷을 추천*해주는 쇼핑몰, '**웨더웨어, 왓투웨어**' 입니다~

# trouble issue
- '기상청 api' 요청 횟수가 제한되어 날씨 정보를 매번 가져오는것에 한계가 있어, 스케줄러를 이용하여 세시간마다 정해진 시간에 가져오게끔 설계하였습니다.

- 판매 상품 글에 대해 페이징 처리를 하여, 로딩 지연시간에 대한 문제를 개선시켰습니다.


# 기술 스택
-   **백엔드:**
    -   **언어:** Java
    -   **프레임워크:** Spring Boot, Spring Security, Spring Data JPA
    -   **라이브러리:** RestTemplate
-   **프론트엔드:**
    -   **언어:** JavaScript, HTML, CSS
   
-   **데이터베이스(DB):** MySQL
